# Screen 01 — Intelligent Home (light preview)
Approved design reference: Cleanova header + tagline and settings; white rounded cards on #F2F2F7; #007AFF storage progress; free space, used and total; Smart Clean card and Smart Scan action; For you cards; floating Home / Media / Storage navigation.
- Real capacity from foundation StorageSession. No hardcoded capacity or reclaimable space.
- Smart Scan currently performs read-only media inventory; no AI or deletion. First grant requires tapping scan again after permission dialog. Results show accessible known sizes only.
- Memory Guard and Space Rescue are visual previews, explicitly marked Coming soon and not interactive.
- Settings, other tabs use existing foundation screens. Light mode is enforced for current phase. The future dark theme implementation is retained.
- Native status/navigation bars, scroll on compact screens, stacked recommendation cards for large text/narrow width. No fabricated screenshot or simulated cleaning success.
- Verify build, unit tests, lint, Android device appearance, permission denial, limited grant, scan cancellation and navigation before approval.
